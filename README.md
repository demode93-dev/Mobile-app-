# Lockhart Surface Solutions — Field Quote Tool

Mobile-friendly Next.js app for tracing a parking lot on satellite view,
generating a real-time seal coating & striping estimate, and exporting a
branded, client-safe PDF quote.

The app has two views baked into the dashboard:

- **Estimator View** (top section) — raw square footage, material costs,
  labor rate, and profit margin. Internal only.
- **Client PDF View** (bottom section) — a live preview of exactly what the
  "Export to PDF" button produces: marked-up service prices and a total,
  never the labor rate, material cost, or margin percentage.

## 1. Local setup

```bash
npm install
cp .env.example .env.local
```

Edit `.env.local` and set `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`. In
[Google Cloud Console](https://console.cloud.google.com/apis/credentials),
create (or reuse) an API key and enable these APIs for that project:

- **Maps JavaScript API** — renders the satellite map (Drawing and Geometry
  libraries ship with it, nothing extra to enable)
- **Places API** — the address search bar
- **Static Maps API** — the polygon snapshot embedded in the PDF

Then run the dev server:

```bash
npm run dev
```

## 2. Deploy for free (Vercel — recommended)

1. Push this repo to GitHub if it isn't already there.
2. Go to [vercel.com/new](https://vercel.com/new) and sign in with GitHub.
3. Import this repository. Vercel auto-detects Next.js — leave the build
   settings as default.
4. Before deploying, open **Environment Variables** and add:
   - `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` = your key from step 1
5. Click **Deploy**. You'll get a URL like
   `https://lockhart-surface-solutions.vercel.app`.
6. Back in Google Cloud Console, edit the API key's **Application
   restrictions** → **HTTP referrers** and add that Vercel domain (and
   `localhost` for local dev). This stops anyone else from using your key.

Every future `git push` to this branch redeploys automatically.

## 3. Deploy for free (Netlify — alternative)

This repo already includes a `netlify.toml` (build command `npm run build`,
publish directory `out`).

1. Push the repo to GitHub.
2. Go to [app.netlify.com](https://app.netlify.com) → **Add new site** →
   **Import an existing project** → pick this repo.
3. Under **Site settings → Environment variables**, add
   `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`.
4. Deploy. Add the resulting `*.netlify.app` domain to the API key's HTTP
   referrer restrictions, same as step 6 above.

## 4. Hand the link to your client (PWA install)

Once deployed, the app is installable as a Progressive Web App — no app
store needed. Text your client the URL and have them:

**iPhone (Safari):** open the link → tap the **Share** icon → **Add to Home
Screen** → **Add**.

**Android (Chrome):** open the link → tap the **⋮** menu → **Add to Home
screen** (or tap the install banner if Chrome shows one) → **Add**.

The app then opens full-screen from their home screen icon, exactly like a
native app, using the Lockhart icon and colors set in
`public/manifest.webmanifest`.

> PWA installability requires HTTPS — both Vercel and Netlify provide this
> automatically on their default domains.

## 5. Updating the brand icon

`public/icons/*.png` are generated by `scripts/generate-icons.mjs` (a small
dependency-free PNG encoder, no image libraries required). Edit the mark in
that script and re-run `node scripts/generate-icons.mjs` to regenerate all
sizes, including the maskable variant Android uses for adaptive icons.
